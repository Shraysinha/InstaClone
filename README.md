# 📸 InstaClone

A full-stack Instagram-inspired social media application where users can create accounts, log in securely, upload posts, interact with content, and experience core social platform functionality in a modern UI.

## 🚀 Features

- User Authentication (Register / Login / Logout)
- Secure authentication using JWT
- Protected routes
- Create and upload posts
- View feed/posts
- Like and interact with content
- User profile page
- Responsive UI
- Backend API integration
- Cookie-based authentication
- MongoDB database support

## 🛠 Tech Stack

### Frontend

- React.js
- JavaScript
- Tailwind CSS
- Axios

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Cookie Parser
- bcrypt

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Shraysinha/InstaClone.git
```

Move into project folder:

```bash
cd InstaClone
```

Install dependencies:

```bash
npm install
```

For frontend:

```bash
cd frontend
npm install
```

For backend:

```bash
cd backend
npm install
```

## 🔐 Environment Variables

Create a `.env` file inside backend:

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```

## ▶️ Run Project

Start backend:

```bash
npm run dev
```

Start frontend:

```bash
npm start
```
